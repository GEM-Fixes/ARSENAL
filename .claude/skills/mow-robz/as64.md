# as64: RobZ on the 64-bit build

Background on the two modes of AS64: skill `mow-games`, skill `mow-mod-start` ("Classic or Enhanced"). Here: what it means for RobZ.

## The short answer
- RobZ's mod.info range 3.262 .. 3.262 makes it a legacy mod: AS64 lists and loads it in Classic mode only [V] (lim VFS-48, VFS-54)
- Enhanced mode (as64+) does not apply it; the game says the mod is made for the other mode [V]
- nothing has to be changed in RobZ to play it in Classic. Check first: `mow_robz_find game as64` (says what the range means), `mow_robz_issues game as64 area as64`

## Classic mode
| point | state |
|---|---|
| loads, lobby, match starts | [V] on the 1.30.10 Workshop version |
| damage system | scripts read [V]; in test games some units did no damage [T] (`mow_robz_issues area damage`, refmods/robz/systems-test.md) |
| bots | as on the 32-bit game: battle zones only, many bot unit names match no card in 1.30 [V] (trouble.md) |
| texts | RobZ's `.lng` files replace the game's whole; a few newer keys of AS64 can show raw [I] |
| 1.31.x tree | not run [T] |

## An upgraded copy for Enhanced mode
- only as a COPY in a new folder; the installed RobZ stays as it is
- `mow_mod_upgrade` (preview first) or `node tools/upgrade/upgrade.js --help`; then `mow_mod_check` with game as64
- what the upgrade of 1.30 found and what stays open: refmods/robz/upgrade-130.md (`mow_robz_notes file upgrade-130`)
- warnings on an upgraded copy, none seen in play [I]: `mow_robz_issues game as64 area as64` (RZ-UPGRADE)
- an upgraded copy is a different mod for multiplayer: every player needs the same copy (`mow_mp_sync`)
- sub-mods of RobZ must follow: a legacy sub-mod does not load with an Enhanced copy and the other way round (submod.md MODE_MISMATCH)

## Sub-mod made for AS64 only
- stay legacy (same range as RobZ) unless RobZ itself is an upgraded copy
- features that exist only in Enhanced mode are out of reach of a Classic stack: `mow_game_diff`, `mow_limit` before promising one

## Multiplayer between the two games
- whether 32-bit and 64-bit players can share a lobby is a rule of the game, not of RobZ: skill `mow-games`
- same RobZ version and same sub-mods on every machine; Workshop copy against a folder copy of the same version is the classic cause of "different version" (structure.md)

## What is not verified
- Enhanced copy of 1.31.x: not made, not run [T]
- `Require` behaviour on the 32-bit exe [T]
- a full match per army on AS64 [T]; say so when a player asks whether "everything works"
