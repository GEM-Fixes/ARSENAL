## reinstall of our own copy is allowed
$ ARSENAL install mymod --game game
install: mymod -> game/mods/mymod (copy)
installed mymod
rc=0
  marker: {"source":"<tmp>/mymod","link":false,"time":"<time>"}
## uninstall: needs --yes
$ ARSENAL uninstall mymod --game game
would remove: game/mods/mymod (folder and contents)
re-run with --yes to remove
rc=1
  mods/: hand keep mymod
$ ARSENAL uninstall mymod --game game --yes
removed: game/mods/mymod (folder and contents)
removed mymod
rc=0
  mods/: hand keep
## link form
$ ARSENAL install mymod --game game --link

  source still there: true, marker left in source: false
