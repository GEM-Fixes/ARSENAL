# Revision history

The guide is versioned on its own, separately from the tools. The version and date below are printed on the title page of the PDF, together with the git commit the PDF was built from, so a printed copy can always be traced back to its source.

How to revise the guide:

1. Edit the chapter files in `guide/`.
2. Add a row at the top of the table below. Raise the minor number (1.0 → 1.1) for corrections and additions, and the major number (1.x → 2.0) when chapters are reorganised or the game version the guide targets changes.
3. Commit the changes, then rebuild the PDF with `node guide/build-pdf.js` (it refuses to stamp a version that has no row here).
4. To see what changed between two printed copies, compare the commits on their title pages: `git diff <old> <new> -- guide/`.
